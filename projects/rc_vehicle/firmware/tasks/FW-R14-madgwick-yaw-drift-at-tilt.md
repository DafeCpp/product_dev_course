# FW-R14 — Слитый yaw Madgwick дрейфит на статическом наклоне

**Источник:** телеметрия заезда 2026-06-14 (`telemetry_log_14_06.csv`),
анализ при валидации FW-R3
**Приоритет:** LOW (влияет на телеметрию/индикацию, не на курс для control)
**Статус:** [ ] Не начато
**Файлы:** `common/control_components.cpp` (`UpdateWithMag` / Madgwick-feed),
`common/madgwick_filter.*`

## Наблюдение

В записанной телеметрии есть эпизод устойчивого статического наклона
(310–322 с): pitch плавно растёт 13°→24°, `gz≈0`, `speed=0` (машинка почти
неподвижна). В этом окне:

| t, с | pitch | gz   | `heading_deg` (mag PCA) | `yaw_deg` (Madgwick) |
|------|-------|------|--------------------------|----------------------|
| 311  | 13.3  |  0.1 | **42.8**                 | +10.4                |
| 317  | 22.0  | −0.1 | **42.7**                 | −30.0                |
| 320  | 24.2  |  0.0 | **42.7**                 | −54.3                |

- `heading_deg` (PCA-проекция магнитометра, зона FW-R3): держится 42.7°
  намертво, σ≈0.08 за 10 с — тилт-компенсация работает идеально.
- `yaw_deg` (слитый Madgwick): уплывает **~7–8°/с** (+10°→−63°) при нулевой
  угловой скорости. Магнитная коррекция внутри Madgwick на наклоне yaw не
  держит — фильтр интегрирует gyro-bias/шум, а mag-член его не возвращает.

## Влияние

Ограниченное. Потребители курса разделены:
- `heading_deg` (надёжный) → кормит EKF
  (`control_loop_processor.cpp` `ctx_.ekf.UpdateHeading(...)`) → курс для
  control/auto-drive на наклоне твёрдый. **Практическая цель R3 достигнута.**
- `yaw_deg` (дрейфит) → телеметрия (`control_components.cpp`,
  `telemetry_builder.cpp`), диагностика, self-test,
  `stabilization_pipeline.cpp` (yaw-индикация). Здесь дрейф виден.

## Возможные направления

1. Поднять вклад mag-члена Madgwick (beta/gain) на наклоне либо адаптивно
   при низкой угловой скорости — чтобы mag «притягивал» yaw обратно.
2. Не использовать слитый `yaw_deg` для индикации курса — брать `heading_deg`
   (PCA) везде, где сейчас показывается компасный курс; Madgwick-yaw оставить
   только для относительной динамики.
3. Проверить, корректно ли mag-вектор передаётся в Madgwick при большом
   наклоне (после FW-R3 туда идёт полный mx/my/mz — убедиться, что нормировка
   и опорное поле не вырождаются на pitch>20°).
