# FW-S2.9 — Профили физ-модели машины (разные параметры/конфигурации)

**Источник:** запрос 2026-06-18 (гонять SIL для разных машин/конфигураций)
**Тип:** инфраструктура тестирования (расширение физ-модели)
**Язык:** Python
**Приоритет:** MEDIUM
**Статус:** [ ] Не начато
**Файлы (при реализации):** `firmware/sim/simlib/profiles.py`,
`firmware/sim/profiles/*.json`, `firmware/sim/tests/test_profiles.py`; правки
`validate_logs.py` / `ClosedLoopSim` (выбор профиля).

## Зачем

Физ-модель (FW-S2.4) уже параметризована через `SimParams`, но параметры заданы
дефолтами в коде. Нужно гонять SIL/replay/валидацию для **разных машин и
конфигураций** (масса, база, ЦМ, мотор, серво, шины): сравнивать поведение,
держать набор эталонных профилей, быстро переключаться и хранить подогнанные под
конкретное шасси параметры (результат FW-S2.6).

## Объём

- **`simlib/profiles.py`** — реестр именованных профилей `SimParams`
  (например `default`, `kids_light`, `heavy`, `drift`): `get_profile(name)`,
  `list_profiles()`. Профиль = `SimParams` с переопределёнными полями.
- **Файловый формат (JSON)** — `load_profile(path) -> SimParams`,
  `save_profile(params, path)` (поля = имена dataclass `SimParams`); каталог
  `firmware/sim/profiles/` с эталонными json.
- **Интеграция:**
  - `validate_logs.py --profile <name|path>` (старт подгонки с профиля; опц.
    `--save-profile out.json` для подогнанного — мост к FW-S2.6).
  - `ClosedLoopSim(params=get_profile(...))` (уже принимает `SimParams`).
  - replay/closed-loop сценарии можно параметризовать профилем.
- **Тесты** (`test_profiles.py`): профили грузятся и отличаются; round-trip
  JSON save/load == исходный `SimParams`; модель ведёт себя различно (напр.
  «тяжёлая» машина разгоняется медленнее «лёгкой» при том же газе); неизвестный
  профиль → понятная ошибка.

## Критерии приёмки

- [ ] Именованные профили + загрузка/сохранение JSON; ≥2–3 эталонных профиля.
- [ ] CLI/гарнесс умеют выбирать профиль; closed-loop/валидация гоняются с разными.
- [ ] pytest: round-trip JSON, различие поведения между профилями.
