# FW-R10 — LSM6DS3 (оригинальный, WHO_AM_I=0x69) не распознаётся драйвером

**Источник:** железная сессия 2026-06-12 (тест ветки test/wave-4-and-rf1)
**Приоритет:** HIGH (датчик на плате не работает)
**Статус:** [x] Реализовано (PR)
**Файлы:** `common/lsm6ds3_spi.cpp`

## Проблема

Драйвер принимал только WHO_AM_I `0x6A` и `0x6C`, причём комментарии к
константам были перепутаны. По даташитам ST:

| Чип | WHO_AM_I |
|---|---|
| LSM6DS3 (оригинальный) | **0x69** |
| LSM6DS3TR-C / LSM6DSL / LSM6DSM | 0x6A |
| LSM6DSO | 0x6C |

Плата с классическим LSM6DS3 стабильно отвечала `0x69` (5 попыток подряд
в логе), но драйвер возвращал ошибку → прошивка стартовала без IMU →
из-за FW-R9 уходила в reboot-loop.

Лог с железа:

```
I lsm6ds3_spi: WHO_AM_I attempt 0: rc=0, value=0x69
...
I lsm6ds3_spi: WHO_AM_I attempt 4: rc=0, value=0x69
E imu: IMU: датчик не обнаружен
```

## Решение

Добавлено значение `0x69` в допустимые, константы переименованы по
фактическим чипам, комментарии исправлены. Регистровая карта используемых
регистров (CTRL1_XL/CTRL2_G/CTRL3_C, OUTX_L_G) и чувствительности
(0.061 mg/LSB при ±2g, 8.75 mdps/LSB при ±250dps) у всей линейки совпадают —
других изменений не требуется.
