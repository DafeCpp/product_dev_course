# Валидация дорожного шума IMU — 2026-08-02 (LOS-287)

## Данные и метод

Проверены 17 CSV из корневого `test_runs/` (~250 тыс. строк). Для каждого IMU-
канала вычиталось centred moving average на 21 тик; края окна исключались.
Скоростные коэффициенты калибровались по `telemetry_log_day_02_08_26.csv` и
`telemetry_log_night_02_08_26.csv`: только эти длинные дорожные логи одновременно
покрывают стоянку и устойчивое движение до 2.5–4 м/с без явно разошедшейся EKF-
скорости. `telemetry_log_long_kids.csv` использован как независимая проверка
электронного пола на неподвижной машине (σ(ax) ≈ 0.005 g).

Воспроизводимая команда для исходного unconstrained fit:

```bash
python validate_logs.py --fit-road-noise \
  --road-logs ../../../../test_runs/telemetry_log_day_02_08_26.csv \
              ../../../../test_runs/telemetry_log_night_02_08_26.csv \
  --profile fitted_2026_07_18
```

У accel-каналов ACF lag-1 на скорости около 2.5 м/с находится в диапазоне
−0.06…+0.10 при шаге телеметрии 10–11 мс: белый шум достаточен. У rate-каналов
корреляция существенна: `gx` lag-1 ≈ 0.45, `gy` lag-1 ≈ 0.72. Fit coherent
angle/rate AR(2)-модели дал 10.68 Гц для roll, 6.72 Гц для pitch и общий damping
0.279. Округлённый профиль воспроизводит ACF lag-1 0.50/0.71.

## Параметры профиля

Линейные σ(v) закреплены как консервативные округлённые линии между низкоскоростным
полом и дорожными корзинами 2.5 м/с:

- `ax`: `0.03 + 0.09·|v|` g;
- `ay`: `0.045 + 0.19·|v|` g;
- `az`: `0.05 + 0.18·|v|` g;
- roll-rate: `8 + 15·|v|` dps;
- pitch-rate: `6 + 12·|v|` dps;
- roll/pitch resonator: 10.7/6.7 Гц, damping 0.28.

Параметры записаны в `fitted_2026_08_02`. Старые измеренный и синтетические
профили оставлены clean-signal для обратной совместимости; `ClosedLoopSim()` с
дефолтным `SimParams()` включает ту же дорожную калибровку с `seed=0`.

## Closed-loop критерий

В Kids-режиме, после разгона с ровным газом и ограничением скорости 2 м/с,
чистый сигнал не включает accel limiter. Дорожная модель включает его примерно
на 26% steady-state тиков и даёт тысячи воспроизводимых переключений за 20 секунд,
что попадает в наблюдавшийся дорожный диапазон порядка 20–45%.
