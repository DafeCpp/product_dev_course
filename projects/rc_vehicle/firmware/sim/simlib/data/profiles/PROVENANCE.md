# Профили физ-модели (FW-S2.9)

| Профиль | Категория | Происхождение | Отличие от `fitted_2026_07_18` |
|---------|-----------|---------------|--------------------------------|
| `default` | baseline | дефолты `SimParams` (FW-S2.4) — прикидка на глаз | другой мотор/серво/сопротивление, top speed 10.0 м/с |
| `fitted_2026_07_18` | **измерено** | joint-фит по 4 логам тест-запуска LOS-213, отчёт `reports/validation-2026-07-18.md` | — |
| `fitted_2026_08_02` | **измерено** | динамика 2026-07-18 + дорожный шум по `test_runs/`, отчёт `reports/validation-2026-08-02-road-noise.md` | stateful шум accel + roll/pitch |
| `light` | синтетика | m=2 кг; `max_accel = F/m`, `drag ∝ 1/m`, `Iz, Ca ∝ m` | резче транзиент, тот же top speed |
| `heavy` | синтетика | m=6 кг, те же законы масштабирования | вялый разгон, тот же top speed |
| `drift` | синтетика | низкое μ: `Car` −60%, `Caf` −20%, тяга ограничена сцеплением | оверстир, **нужен `dynamic=True`** |

Измерены `fitted_2026_07_18` (динамика) и `fitted_2026_08_02` (та же динамика
плюс дорожное возбуждение IMU). Остальные три профиля — расчётные: они выведены из
измеренного применением законов масштабирования, видных прямо в `VehicleModel.step`, но **ни одно
из шасси не взвешивалось и не прогонялось**. Их нельзя цитировать как характеристику реальной
машины — только как «правдоподобно отличающиеся» конфигурации для проверки поведения SIL.

Законы масштабирования (одинаковый мотор, разная масса):

- сила мотора `F = m·a = 3.0 × 8.94 = 26.82 Н` ⇒ `max_accel = F/m`;
- `drag_coeff` имеет размерность 1/с и равен `c/m` для линейного сопротивления `c·v` ⇒ `∝ 1/m`;
- отсюда `v_ss = max_accel / drag_coeff = 7.93 м/с` **инвариантна к массе** — отличается только
  транзиент разгона (это и проверяет `tests/test_profiles.py`);
- `Iz ∝ m` (груз распределён по той же площадке), `Caf/Car ∝` нормальной нагрузке `∝ m`.

Профиль `light` **не** является «детским режимом»: он резче базового. Лимиты газа/скорости для
детей — политика прошивки (`KidsMode`/`KidsPreset`), а не свойство шасси.

Подогнать профиль под своё шасси: `python validate_logs.py <log.csv> --save-profile my.json`.

Исторические `fitted_2026_07_18`/`light`/`heavy`/`drift` хранят нулевые
`road_*_sigma`: это явные clean-signal профили. `default` и
`fitted_2026_08_02` содержат калибровку LOS-287.
