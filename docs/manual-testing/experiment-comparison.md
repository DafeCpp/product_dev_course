# Сценарии: сравнение прогонов (Experiment comparison)

Раздел сравнения метрик нескольких runs эксперимента (`/experiments/:experimentId/compare`,
кнопка «Compare Runs» на деталях эксперимента).

**Где реализовано:**
- Страница `pages/ComparisonPage.tsx`; API `src/api/comparison.ts`.
- Сравнение: `POST /api/v1/experiments/{experimentId}/compare` с телом `{ run_ids, metric_names }`.
- Экспорт: `GET /api/v1/experiments/{experimentId}/compare/export?run_ids=&names=&format=csv|json`.

**Предусловие:** авторизован как `admin`; есть эксперимент с ≥2 runs, у которых есть метрики
(см. [`crud-lifecycle.md`](crud-lifecycle.md), [`telemetry-e2e.md`](telemetry-e2e.md)).

---

### TC-CMP-01 — Открытие страницы сравнения
**Предусловие:** открыты детали эксперимента с несколькими runs.

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Нажать «Compare Runs» | Переход на `/experiments/:id/compare`; список доступных runs отображается |
| 2 | Проверить консоль/HTTP | Без ошибок; страница отрисована |

**Факт (2026-07-16):** ✅ Переход на `/experiments/:id/compare` через ссылку «Compare Runs» с деталей эксперимента; страница отрисована («Выберите runs для сравнения»), консоль чистая.

---

### TC-CMP-02 — Сравнение метрик по нескольким runs
**Предусловие:** на странице сравнения ≥2 runs с метриками.

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Выбрать 2+ runs и метрики, нажать «Compare» | `POST .../compare` → `200`; таблица/график метрик по выбранным runs |
| 2 | Изменить набор метрик/runs | Результат пере-считывается |

---

### TC-CMP-03 — Экспорт сравнения
**Предусловие:** выполнено сравнение (TC-CMP-02).

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Экспорт в CSV | `format=csv` → `200`, корректный CSV |
| 2 | Экспорт в JSON | `format=json` → `200`, корректный JSON |

---

### TC-CMP-04 — Граничные случаи (негатив)
| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть compare у эксперимента без runs | «Нет доступных runs», кнопка Compare неактивна |
| 2 | Выбрать 1 run | Подсказка «Выберите runs и нажмите Compare…»/сравнение с одним рядом, без `500` |
| 3 | Метрика без данных у части runs | Пропуски отображаются корректно (null/‑), без падения |

**Факт (2026-07-16):** ✅ Шаг 2 (эксперимент с единственным run `Run 1`): чекбокс run отображается, кнопка «Compare» задизейблена с подсказкой «Выберите хотя бы один run» (до выбора чекбокса) — граничное состояние обработано без падений. Шаг 1 и 3 (эксперимент без runs, метрика без данных у части runs) не прогонялись отдельно.
