# Сценарии: Telemetry Viewer (live / history / экспорт)

UI-раздел **Телеметрия** (`/telemetry`): живой поток (SSE), исторический запрос, фильтры и выбор
датчиков, экспорт, обработка пустых/ошибочных данных. Серверный путь ingest→конверсия→БД описан в
[`telemetry-e2e.md`](telemetry-e2e.md) и здесь **не дублируется** — фокус на клиентском workspace.

**Где реализовано:**
- Страница `pages/TelemetryViewer.tsx` (декомпозиция LOS-97) + `components/telemetry/*`,
  хуки `useLiveTelemetryWorkspace.ts`, `useTelemetryHistory.ts`, `useTelemetryViewerState.ts`.
- Live: SSE-стрим (см. корректность URL — регресс BUG-F-004/005).
- History: запрос по диапазону/датчикам через `src/api/telemetry.ts`.
- Экспорт: `TelemetryExportModal.tsx`.

**Предусловие:** авторизован как `admin`; есть датчик с телеметрией (см. [`telemetry-e2e.md`](telemetry-e2e.md) TC-TELE-03).

---

### TC-TELE-08 — Live-поток телеметрии (SSE)
**Предусловие:** открыт `/telemetry`, есть активный датчик.

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Выбрать датчик/сессию, включить live | SSE-подключение открывается (URL корректный, регресс BUG-F-005 не воспроизводится), значения приходят |
| 2 | Проверить график | Точки по `raw` (и `physical` при активном профиле) отрисованы; консоль без ошибок |
| 3 | Остановить/переключить датчик | Стрим закрывается/переоткрывается без утечек соединений |

---

### TC-TELE-09 — Исторический запрос и фильтры
**Предусловие:** есть исторические записи.

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Задать диапазон времени и датчик(и), выполнить запрос | `200`, данные отрисованы на графике/в таблице |
| 2 | Сузить/расширить диапазон, поменять выбор датчиков | Данные пере-запрашиваются согласно фильтрам |
| 3 | Диапазон без данных | Пустое состояние, без ошибок консоли (см. TC-TELE-11) |

---

### TC-TELE-10 — Экспорт телеметрии
**Предусловие:** выбран датчик с данными.

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть `TelemetryExportModal`, выбрать формат | Модалка экспорта открывается |
| 2 | Запустить экспорт | Файл/ответ формируется (`200`), формат соответствует выбранному |
| 3 | Экспорт при пустой выборке | Понятное сообщение/пустой результат, без `500` |

---

### TC-TELE-11 — Пустые и ошибочные данные (негатив)
| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть `/telemetry` без выбранного датчика | Нейтральное пустое состояние, без ошибок в консоли |
| 2 | Выбрать датчик без записей | «Нет данных», график пуст, без `500` |
| 3 | Оборвать backend (или запросить недоступную сессию) | Ошибка показывается тостом/баннером, UI не падает; в консоли только ожидаемый `4xx/5xx` |
