# Сценарии: Admin — Rate Limits & QoS

Раздел **Rate Limits & QoS** (`/admin/rate-limits`): конфигурация ограничений и качества сервиса
для auth / experiment / telemetry. По сути — специализированный UI поверх config-service
(см. [`admin-configs.md`](admin-configs.md)).

**Где реализовано:**
- Страница `pages/RateLimitsQos.tsx` + `pages/rateLimits/*` (`AuthQosForm`, `ExperimentQosForm`,
  `TelemetryRateLimitsForm`).
- Хранение — через config-service (`/api/config-service/v1`, ADR-009), с той же
  оптимистической блокировкой (`If-Match`/`ETag`), что и в [`admin-configs.md`](admin-configs.md).
- Поля Auth QoS: TTL access-токена (сек) / TTL refresh-токена (сек) и пр.
- Доступ к разделу: nav требует `configs.view`.

**Предусловие:** авторизован как `admin` (`configs.view` + права на запись).

---

### TC-QOS-01 — Открытие раздела и формы
**Предусловие:** открыт `/admin/rate-limits`.

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть раздел | Формы Auth / Experiment / Telemetry QoS отрисованы; загрузка текущих значений `200`; консоль чистая |

---

### TC-QOS-02 — Сохранение конфигурации QoS
**Предусловие:** открыта одна из форм (напр. Auth QoS).

| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Изменить значение (напр. TTL access-токена), «Сохранить» | Запрос сохранения → `200`; значение персистентно после перезагрузки |
| 2 | Experiment QoS / Telemetry rate limits — аналогично | Сохранение `200`, значения применяются |

---

### TC-QOS-03 — Валидация и dry-run (негатив)
| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Ввести недопустимое значение (отрицательное/нечисловое TTL) | Клиентская/серверная валидация, `400/422`, сохранение отклонено |
| 2 | «Проверка конфигурации» (dry-run, если есть) | Валидация без записи |

---

### TC-QOS-04 — Оптимистическая блокировка и RBAC (негатив)
| # | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Сохранение с устаревшей версией (конкурентная правка) | `409/412` (как в [`admin-configs.md`](admin-configs.md) TC-CONFIG-05) |
| 2 | Пользователь без `configs.view` открывает раздел | «Нет доступа»/`403`; пункт скрыт в nav |
