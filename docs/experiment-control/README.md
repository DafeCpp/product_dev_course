# Experiment Control — рабочее пространство

Черновое пространство для проработки подсистемы управления экспериментом:
от ручных команд оператора до замкнутых контуров регулирования.

> **Это не RFC.** Здесь хранятся разведочные заметки, варианты архитектуры,
> open questions. Итоговое архитектурное решение оформлено в
> [RFC-0004](../RFC/rfc-0004-experiment-control-architecture.md) (Draft);
> детализация — RFC-0004a (протокол) и RFC-0004b (API/UI), задачи
> LOS-75 / LOS-73.

## Контекст

- Задача происходит из [эпик RFC-0004 (LOS-66)](https://linear.app/lostpointer/issue/LOS-66) — «RFC: система управления
  экспериментом (closed-loop control)».
- Прецедент **edge-control** уже существует в проекте: прошивка RC Vehicle
  (`projects/rc_vehicle/firmware`) реализует локальный контур 500 Гц через
  Madgwick + Butterworth + PID. Эту же модель предлагается распространить на
  лабораторные стенды.
- Смежные RFC-идеи (см. связанные Linear issues):
  - [RFC-0002 Computed Channels (LOS-138)](https://linear.app/lostpointer/issue/LOS-138) — вычисляемые величины (Mach, расход и др.);
    могут использоваться как вход rule engine.
  - [RFC-0003 Alerts + Dashboards (LOS-139)](https://linear.app/lostpointer/issue/LOS-139) — rule engine для порогов; переиспользуется
    в closed-loop автоматизации.

## Документы

- [options-comparison.md](options-comparison.md) — сводная таблица вариантов
  по нефункциональным параметрам (частота, задержка, отказоустойчивость,
  стоимость, применимость). Для обсуждения верхнего уровня.
- [design-notes.md](design-notes.md) — технические детали: варианты
  архитектуры, Gateway pattern, latency-бюджет, протоколы, open questions,
  следующие шаги.
- [customer-questions.md](customer-questions.md) — структурированный
  список вопросов к заказчику для discovery-сессий. Сгруппирован по
  темам (кейсы, DAQ, управление, safety, анализ, эксплуатация,
  инфраструктура). Отдельная большая секция про DAQ для тензодатчиков,
  включая MCU-вариант. Внизу — накопленные ответы заказчика.
- [spike-mcu-control-loop.md](spike-mcu-control-loop.md) — отчёт спайка
  LOS-76: контур 500 Гц на MCU поверх CANopen (host-SIL, vcan-риг,
  ESP32-S3), измерения качества/джиттера/RTT, вердикты по SYNC-режиму
  и CANopenNode, требования к плате заказчика.
- [safety-review.md](safety-review.md) — safety review LOS-70:
  hazard-анализ (ISO 12100), нормативная рамка (machinery vs
  aerospace), архитектура цепи аварийного останова, решение по safety
  PLC, три класса останова и координация группы каналов, требования к
  Safety Monitor и к железу стенда.
