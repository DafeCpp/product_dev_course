# Инструкции для Codex и других coding agents

Эти инструкции действуют для всего репозитория.

Перед работой с задачей, кодом или PR обязательно прочитайте:

1. [docs/pr-guidelines.md](docs/pr-guidelines.md) — единый регламент работы с Linear, ревью, CI, merge и закрытием задач. Следуйте таблице переходов статусов и условиям `Done`.
2. [CLAUDE.md](CLAUDE.md) — архитектура, команды и ограничения компонентов.
3. [docs/branching-model.md](docs/branching-model.md) — целевые ветки и выпуск релизов.

Регламент одинаков для Codex и Claude Code. Изменяйте процесс в `docs/pr-guidelines.md`, сохраняя ссылки на него в обоих корневых файлах инструкций. Не создавайте отдельную копию правил для каждого агента.

Выполняйте действия в пределах запроса пользователя. При поручении довести задачу до merge сопровождайте PR после создания: CI, замечания, повторное ревью и подтверждение merge. Если следующий шаг заблокирован, сообщите конкретную причину, ссылку на PR и оставшееся действие; не заявляйте, что задача завершена.
