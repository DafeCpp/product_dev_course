# PR review and merge

1. Найти корень репозитория, прочитать корневые `AGENTS.md` и `CLAUDE.md`, затем [docs/pr-guidelines.md](../../../docs/pr-guidelines.md).
2. Прочитать и выполнить общий алгоритм [«Цикл Codex review → CI → merge»](../../../docs/pr-guidelines.md#цикл-codex-review--ci--merge), а также условия merge и закрытия Linear в том же документе. Если документ недоступен, сообщить блокер; не заменять его предположениями.
3. Использовать URL/номер PR из запроса и разрешённый объём действий. Сохранять уже данное поручение merge между итерациями; загрузка навыка сама по себе не даёт такого разрешения.
4. Работать через доступный GitHub connector/MCP или `gh`. Не считать создание PR, отсутствие замечаний или старый результат Codex завершением цикла. Проверять CI и одобрение одного текущего head SHA перед merge.

Хранить алгоритм только в `docs/pr-guidelines.md`. Обновлять оба входных SKILL.md при изменении способа вызова или пути к общему документу.
