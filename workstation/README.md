# АРМ СКИ-60

## Экспорт результатов

`ResultExportService` экспортирует результаты постсеансной обработки в три формата:

- `.xlsx` — книга Office Open XML;
- `.xls` — совместимый с Excel 2003 SpreadsheetML;
- `.txt` — UTF-8, колонки разделены табуляцией.

Каждая строка содержит полную, интегральную и статическую характеристики одновременно
в МПа и кгс/мм². Пересчёт выполняется по соотношению
`1 кгс/мм² = 9,80665 МПа`. Числа сохраняются с инвариантным десятичным разделителем,
а дата — в ISO 8601, поэтому выгрузка не зависит от локали рабочего компьютера.

Экспортёры пишут в переданный поток и не используют Microsoft Office или интернет,
что позволяет применять их на автономной стендовой машине.
